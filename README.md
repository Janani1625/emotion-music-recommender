## Description
A Python-based application that analyzes user emotions from text input and recommends suitable music genres accordingly.

## Features
- Detects emotion using keyword-based text analysis
- Recommends music based on detected mood
- Simple command-line interface
- Beginner-friendly logic

## Technologies Used
